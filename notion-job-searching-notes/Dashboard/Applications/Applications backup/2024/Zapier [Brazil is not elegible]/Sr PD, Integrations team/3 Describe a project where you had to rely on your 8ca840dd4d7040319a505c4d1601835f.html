Data connector vs Data Query vs Job

A data connector most specifically refers to the connection to the external data provider.

This includes any credentials needed to connect, but not the specific query to use for a project’s jobs. However, it is still common to refer to the “connector/connection for a project” as the connection plus the query.

When a query runs, it triggers a job.

There isn’t any resource that represents a query, and a connection isn’t really tied to a project. Projects have jobs which ran, jobs capture the query+connection used to run. Because of this, there isn’t really the concept of updating a project to capture the data that a past query ran.
