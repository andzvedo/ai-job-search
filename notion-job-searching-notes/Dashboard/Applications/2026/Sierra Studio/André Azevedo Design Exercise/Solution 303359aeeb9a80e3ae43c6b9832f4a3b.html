Solution

User flow

  1. Home: Get Started - Empty

1.2. Home: Filled with past Comparisons

  1. Comparison

    Fair comparison. Pairwise. Chat simultaneously with booth models using the same setup and the same message.

    1. Settings
      1. Configure System prompt, Temperature, Advanced settings…
    1. Chat
      • Chat View: 3 options
        • Uma sendo lado a lado.
        • Outra sendo uma em cima da outra
      • Chat Messages
        • Prompt 1
          • Model A Output
          • Model B Output
        • Prompt 2
          • Model A Output
          • Model B Output
        • And so on…
    1. Evaluate

      Focusing on qualitative evaluation

      1. Review and evaluate the outputs individually for each prompt
        • Choose between Like or Dislike
      1. Share a review note explaining your decision (Optional)
        • What did you like/ dislike about this response? What caught my attention? Was the model too verbose?
    1. Results

      Overall performance:

      The app AI will put together in a nice way explaning the reasons of why each model gets that eval ate the end. Como se fosse um relatorio resumido, não só metricas quant

      • Ex: Modelo A foi o que você mais achou que foi acertivo e objetivo. Já o Modelo B você ressaltou que foi mais amigável, mas não conseguiu atingir todas as expectativas, como na resposta da pergunta A.
      • Share or Export results:
        • JSON
        • Markdown
      • (tone, correctness, helpfulness, safety, verbosity, follow-up behavior)

This step is to allow the user enter any type of info that can support their answer - Thumbs up or down. For example:

This anwser have strong biases towards A and B...

There are these two options (Good/bad), to allow users express their point of view of what is working, what is not, once the focus is Qualitative eval, vibes eval

At the end of the Chat, all the notes/review will compose the final Veredict.

Vamos integrar as features de Chat com a Compare, transformando em um único fluxo:

1º envia mensagem

2º Outputs começam a aparecer

3º As duas respostas são finalizadas

4º Usuário precisa avaliar antes de enviar uma outra mensagem e continuar o chat;

  • Avaliar cada resposta, escolhendo se é bom/ruim, com thumbs up ou down;
  • E como opcional, deixar comentários sobre cada output que de suporte a sua avaliação.

5ª Pode mandar a próxima mensagem, e o fluxo segue, até terminar a conversa.
