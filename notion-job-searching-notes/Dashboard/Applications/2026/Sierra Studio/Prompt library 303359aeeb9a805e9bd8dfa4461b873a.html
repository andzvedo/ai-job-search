Component Details

Model Cards

  • Size: 160px × 120px
  • Border radius: 12px
  • Shadow: 0 2px 8px rgba(0,0,0,0.1)
  • Provider logo: 24px circular
  • Selected state: 2px border + checkmark

Chat Bubbles

  • User: Gray background, left-aligned
  • AI: Colored backgrounds by provider, right-aligned
  • Border radius: 18px (user), 18px 4px (AI for tail)
  • Padding: 12px 16px

Interactive Elements

  • Buttons: 44px min height, 12px radius
  • Sliders: Custom thumb, smooth animations
  • Text inputs: 1px border, focus states
  • Loading: Skeleton screens + pulsing dots

Design System

Colors

  • Primary: #2563EB
  • Secondary: #7C3AED
  • OpenAI: #10A37F
  • Google: #4285F4
  • Anthropic: #D97706
  • Meta: #0866FF
  • Mistral: #FF6B35

Typography

  • Headings: Inter 600
  • Body: Inter 400
  • Code: SF Mono
  • Scale: 32/24/20/16/14/12

Spacing

  • Base unit: 4px
  • Components use 4px multiples
  • Safe areas respected
  • Touch targets: 44px minimum

Microinteractions

  • Card hover: scale(1.02) + shadow
  • Button press: scale(0.98) + haptic
  • Streaming text: character-by-character reveal
  • Screen transitions: easeInOut 300ms

Accessibility

  • 4.5:1 contrast minimum
  • VoiceOver labels
  • Large text support
  • Color-independent model identification

This design emphasizes speed and clarity for technical users, with innovative split-screen comparison that enables rapid qualitative assessment of model differences.
